# ¿Qué es OWASP?

OWASP es la comunidad global de referencia que define cómo construir, probar y mantener software seguro sin intensiones comerciales ni marcas vendiendo soluciones propietarias.

# Principios Fundamentales de OWASP

- **Neutralidad e Independencia**: No están vinculados a ningún proveedor de software o ciberseguridad. Sus recomendaciones son objetivas.
- **Comunidad Abierta**: Cualquier persona (estudiantes, investigadores, desarrolladores) puede colaborar, aportar o utilizar sus recursos gratis.
- **Enfoque Práctico**: No se quedan solo en la teoría; crean herramientas, guías y estándares aplicables al día a día del desarrollo de software (DevSecOps).

# Los Proyectos Principales de OWASP

## Documentos y Estándares

- **[OWASP Top 10](https://owasp.org/www-project-top-ten/)**: Es su documento más famoso. Lista los 10 riesgos de seguridad más críticos en aplicaciones web (por ejemplo: inyecciones, fallos criptográficos, control de acceso defectuoso).
- **OWASP ASVS (Application Security Verification Standard)**: El estándar que mencionaste antes. Define los requisitos exactos de seguridad que debe cumplir un sistema según su nivel de criticidad.
- **OWASP SAMM (Software Assurance Maturity Model)**: Un marco para evaluar y mejorar el ciclo de vida de desarrollo seguro (SDLC) en una organización.

# Herramientas Prácticas

- **OWASP ZAP (Zed Attack Proxy)**: Una herramienta gratuita de escaneo de vulnerabilidades (pentesting) muy popular para auditar aplicaciones web.
- **OWASP Dependency-Check**: Herramienta para detectar componentes o librerías de terceros con vulnerabilidades conocidas en tu código.
- **OWASP Juice Shop**: Una aplicación web deliberadamente insegura construida para practicar hacking ético y pruebas de seguridad.
